# Meeting Planner Launcher

Static meeting planner that opens [timeanddate.com](https://www.timeanddate.com/worldclock/meeting.html) with the right cities for your participants.

## Live site

After the first successful deploy, the app is published at:

**https://mathias_roehring.github.io/meeting-planner-launcher/**

(GitHub Pages URL for the `main` branch workflow in repo `meeting-planner-launcher`.)

## Local preview

Open `index.html` in a browser, or serve this folder:

```bash
npx --yes serve .
```

## Deploy

Pushes to `main` run `.github/workflows/deploy-pages.yml`, which publishes the contents of this folder to GitHub Pages.
